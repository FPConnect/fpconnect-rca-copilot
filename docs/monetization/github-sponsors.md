# GitHub Sponsors — FPConnect / OPSPECTA

## Profile headline
**Support open-source reliability intelligence for healthcare technology operations.**

## Profile description
OPSPECTA is an open-source reliability and service-operations platform built by FPConnect for healthcare and MedTech environments.

The project focuses on organizing service records, logs, equipment history and operational indicators to support troubleshooting context, root-cause hypothesis review, availability analysis and more traceable service decisions.

Sponsorship helps fund:
- reusable open-source reliability components;
- documentation and test coverage;
- anonymized demo datasets and examples;
- integrations and developer tooling;
- community support and public technical content.

Commercial diagnostics, pilots and implementation work remain separate from sponsorship.

## One-time sponsorships

## Positioning rule
Do not promise:
- clinical outcomes;
- guaranteed downtime reduction;
- regulatory compliance;
- exclusive features in exchange for sponsorship.

Sponsors fund the open-source project. Paid diagnostics, pilots, integrations and consulting use separate commercial agreements.

## After Sponsors is approved
Add a repository funding configuration at `.github/FUNDING.yml` pointing to the approved sponsored account, then add a Sponsor CTA to the README and the public website.
